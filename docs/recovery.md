# Recovery boundary

Recovered on October 30, 2026 from the owner's mounted Google Drive archive. The original project subtree contains 6,229 files, about 97 MB, and the core formatter subtree contains 103 files across several revisions. The archive also includes adjacent internal applications, third party packages, logs, configuration and a nested historical ZIP.

All recovered files and the complete SHA256 inventory are stored outside the repository at `~/.local/share/tft-recovery/`. The original archive on Drive was not modified. An automated marker review flagged 1,786 text files for further inspection. Marker matches are triage, not a complete privacy review or proof that unmatched files are safe.

Examined the current formatter markup, main JavaScript formatting routines, AJAX location lookup, function inventory and version layout. Confirmed structured caller details, reusable text templates, general and escalation formatting, location suggestions, specialist forms and clipboard output. Historical infrastructure and browser assumptions require replacement.

The new application was authored with generic categories and fictional examples. No recovered files were imported into Git. Original credentials, staff details, directory records, internal URLs, operational instructions, corporate branding and third party bundles stay outside this project.

The owner reports deployment to an 80 person support operation. That history is owner supplied and has not been independently verified from deployment records. Public claims and attribution wording remain a later review item.

Before any historical content is reused: inspect it, assess its purpose and dependencies, remove sensitive details, review third party rights, then scan the proposed source and assets. A word replacement pass is insufficient. Review screenshots, binary documents and nested archives separately. Never run the recovered legacy app against its historical endpoints.
