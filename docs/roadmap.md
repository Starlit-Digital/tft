# Roadmap

## Implemented in 0.2.0

The local demo has a tabbed workspace, queue and search, fictional scenarios, assignment, routing, escalation, resolution, reopening and activity history. Fields, workgroups and output templates have scoped settings. Ticket transfer supports JSON and tagged text. The source package includes the complete implementation, tests, change history and upgrade documentation.

## Next work

1. Complete private historical review, including nested archives and binary assets, without importing original business records. Recover a matching datastore if one is found.
2. Extend configurable questionnaires, reusable snippets, external field mapping and human readable import adapters based on a specified source format.
3. Design real staff accounts, organization permissions and authenticated event attribution, then notifications, retention, quotas and production operations. Demo agent names and session boundaries do not supply those capabilities.
4. Complete real browser verification of desktop and 320px reflow, enlarged text, keyboard operation, focus return, shades, contrast, reduced motion and clipboard permissions. Add product icon artwork from the approved family when branding is requested.
5. Prepare isolated public demo hosting with lifecycle expiry, quotas, reviewed configuration and live verification as a separate deployment scope.
